常见问题

python 和 pip3 命令无反应怎么办？
多数是安装时未勾选 Add Python to PATH。重新运行安装包勾选该选项，或手动把 Python 安装目录与 Scripts 子目录加入系统环境变量 PATH 后重开 cmd。
需要额外安装哪些库？
书中建模用到 pandas、numpy、scikit-learn 与 Keras（tensorflow）。常规的 pip3 install pandas numpy scikit-learn tensorflow 即可；notebook 首次运行报缺少哪个库就补装哪个。
为什么用 Jupyter notebook 而不是直接跑脚本？
notebook 把代码、输出与说明按单元格组织，适合分步骤演示与教学对照；书中 4.3 各步骤的截图均来自 notebook 界面，配套 notebook 也按此组织。
