1偏最小二乘（PLS）点击带"讲"标记的行查看逐行讲解
1from sklearn.cross_decomposition import PLSRegression [引入库]
2pls2 = PLSRegression（n_components=2） [以默认参数建立PLS模型]
3pls2.fit（x_train, y_train） [运用训练集数据拟合模型]
4y_pred = pls2.predict（x_test） [运用测试集数据进行预测]
5print（y_pred） [报告利用建立的偏最小二乘回归对测试数据进行预测的结果]
深度解读
线性方法家族的分工：PLS 在压缩特征的同时保留与收益相关的方向；岭回归收缩系数但保留全部变量；Lasso 把不重要的系数压到零（变量选择）；弹性网络取两者的加权。它们都适合特征多（94 个）、样本相关的场景。

7人工神经网络（Keras）点击带"讲"标记的行查看逐行讲解
1from keras.models import Sequential [引入库]
2from keras.layers import Dense [引入库]
3from keras.layers import Dropout [引入库]
4model = Sequential() [构建人工神经网络模型]
5model.add(Dense(units = 26, kernel_initializer = 'uniform', activation = 'relu', input_dim = 94)) [使用 add() 函数将层添加到模型中。其中，add函数的参数是 Dense() 函数，units定义了该特定层中的神经元的数量为26。kernel_initializer定义了隐藏层中不同神经元权重的起始值为“均匀”，这意味着权重将使用来自均匀分布的值进行初始化。Activation指定特定隐藏层中神经元的激活函数为relu。input_dim定义隐藏层的输入数量为94。]
6model.add(Dense(units = 1, kernel_initializer = 'uniform')) [构建输出层]
7model.compile(optimizer = 'adam', loss = 'mean_squared_error', metrics = ['accuracy'])
8model.fit(x_train, y_train, batch_size = 5, epochs = 10) [运用训练集数据拟合模型]

10print(y_pred) [报告利用建立的神经网络模型对测试数据进行预测的结果]
深度解读
神经网络的优势在非线性交互：26 个神经元的隐藏层对 94 个特征做非线性变换。书内参数（10 轮训练、批量 5）为演示设定；Gu、Kelly 和 Xiu（2020）的系统比较发现神经网络与树模型（GBRT、随机森林）在收益预测中表现最好。
8样本外 R² 评估点击带"讲"标记的行查看逐行讲解
1from sklearn.metrics import r2_score [引入库]
2r2 = r2_score(y_test, y_pred) [计算]

深度解读
样本外 R² 是机器学习定价的标准成绩单：在测试集上比较各模型。注意月度收益噪声极大，R² 达到千分之几量级即有经济意义（可折算为可观的价差组合收益）。

常见问题

代码复制到 notebook 后报语法错误怎么办？
检查括号是否为全角：书内 Python 代码的部分括号是全角，需要替换为半角后运行；配套 notebook 中已是可运行的版本。
为什么各模型的参数都这么简单？
教学演示以流程为主，参数取默认或直观取值。正式研究中应做交叉验证调参（如 sklearn 的 GridSearchCV），Gu、Kelly 和 Xiu（2020）对每个模型都做了系统的超参数选择。
哪类模型预测月度收益最好？
Gu、Kelly 和 Xiu（2020）的比较中，神经网络与树模型（GBRT、随机森林）的样本外 R² 最高，线性方法次之，这与特征间大量非线性交互有关；书中图 4.3.8、图 4.3.9 的示例结果也是树模型与神经网络领先。
R² 很小是不是模型没用？
不是。月度个股收益的信噪比极低，样本外月度 R² 达到 0.3% 以上就已具备经济价值——按预测值排序构建的多空组合可以产生显著收益，这是机器学习定价文献的标准结论。
