4.2.3多因子模型检验：Fama-MacBeth 回归

这一节做什么

多因子模型的检验有两条路线：以组合排序为基础的时间序列回归（Gibbons 检验），与 Fama 和 MacBeth（1973）的两阶段截面回归。本节演示后者的 Stata 实现：第一步用 asreg 的滚动窗口对每只股票估计因子暴露（beta），第二步把滞后一期的 beta 作为解释变量做逐月截面回归（asreg fmb 或 xtfmb），并对系数均值做 Newey-West 调整。

本节内容包括：
  • asreg 滚动窗口回归：bysort 与 window 选项
  • Fama-MacBeth 两阶段：滞后一期 beta 进入截面回归
  • asreg fmb 与 xtfmb 两种写法

用到哪些数据

FM回归检验.dta
书中 Fama-MacBeth 回归的数据：2000 年 1 月-2019 年 12 月，381933 个股票-月度观测
Stkcd / Mon股票与交易月份（面板标识）
RRf超额收益率
BM / Profit / Invest账面市值比、盈利与投资特征

代码

1第一步：时序回归估计因子暴露（滚动窗口）点击带"讲"标记的行查看逐行讲解
1use " FM回归检验.dta" [打开数据]
2xtset Stkcd Mon [定义面板数据（横截面变量和时间变量）]
3bysort Stkcd: asreg RRf MKT SMB HML , window(Mon 60) [通过asreg的bysort和window选项实现窗口为 60 个月，每次向后移动一个月的分组时间序列回归]
4keep if _Nobs==60 [保留样本数为60的]
5list in 1/10 [以1至10行的数据为例演示。_b_MKT表示MKT的回归系数，其余变量类似。]
深度解读
Fama-MacBeth 检验的逻辑：如果定价模型正确，第二阶段截面回归中因子暴露的系数应显著（风险有价格），而常数项（α）应不显著异于零。第一步的滚动窗口让 beta 随时间更新，比全样本单次回归更贴近实务。
2第二步：截面回归（asreg fmb）点击带"讲"标记的行查看逐行讲解
1gen L_b_ MKT =L. _b_ MKT [将MKT的beta系数滞后一期]
2gen L_b_ SMB =L. _b_ SMB [将SMB的beta系数滞后一期]
3gen L_b_ HML =L. _b_ HML [将HML的beta系数滞后一期]
4asreg RRf L*, fmb newey(4) [经过Newey-West调整的回归检验，L*表示所有滞后一期的回归系数，例如L_b_ MKT]
深度解读
fmb 输出的是各月截面系数的平均值及其 Newey-West t 值——这正是 Fama 和 MacBeth（1973）方法的定义：把每个截面当成一次估计，用系数序列的波动推断显著性，避免了截面相关带来的标准误低估。滞后一期的 beta 是关键细节。
3xtfmb 实现点击带"讲"标记的行查看逐行讲解
1xtfmb RRf L*, lag(4) [经过Newey-West调整的回归]

常见问题

fmb 输出的是每个变量的什么结果？
asreg fmb 对每个月的截面回归分别估计系数，输出的是各月系数的平均值及其 Newey-West t 值（滞后 4 期）：因子暴露前的系数显著说明该暴露带有风险溢价，常数项（α）不显著说明模型定价无系统性偏差。
滚动窗口为什么取 60 个月？
60 个月（5 年）是估计个股因子暴露的常用窗口：太短则 beta 噪声大，太长则反应不了暴露的变化。稳健性检验中常对比 36、60、120 个月窗口。
为什么 beta 要滞后一期？
t 期的 beta 由截至 t-1 期的数据估计而来，直接用当期估计值解释当期收益会引入前视偏差。L. 算子把 beta 后移一个月，保证解释变量在收益实现之前已知。
asreg fmb 和 xtfmb 有什么区别？
两者都实现 Fama-MacBeth 两阶段中的逐月截面回归并输出系数均值的 Newey-West 检验，结果一致；asreg 需 ssc install asreg，xtfmb 需 ssc install xtfmb。书内同时给出两种写法供选择。
