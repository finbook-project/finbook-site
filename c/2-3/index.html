2.3描述性统计分析

这一节做什么

描述性统计分析是实证论文的第一张表，用于反映数据集的基本特征、判断变量度量是否合理、数据处理过程是否合理。本节用 tabstat 演示四种常用形式：全样本汇报、限定年份的子样本汇报、按行业分组汇报，以及条件与分组的叠加使用。

本节内容包括：
  • tabstat 汇报自选统计量（均值、标准差、中位数、极值、观测数）
  • if 条件限定子样本、by() 选项分组汇报的写法
  • 从描述性统计表检查变量量纲、分布偏态与缺失情况

深度解读
描述性统计是实证论文的第一张表。阅读时应关注三个方面：一是变量的量纲与取值范围是否合理，比值型变量的最大值、最小值应落在合理区间内；二是平均值与中位数的差距，差距较大说明分布右偏，此时中位数更能反映集中趋势；三是各变量的非缺失观测数。书中 2.3.2 给出的错误示例中，比值变量的最大值达到数百倍、部分变量的极值明显异常，均为未缩尾或度量错误的典型信号。

常见问题

为什么论文都要报告描述性统计？
描述性统计表反映数据集的基本特征，是读者和审稿人判断数据质量的第一手材料：变量定义是否合理、极端值是否处理、样本量是否支持结论，都可以从这张表中看出。
tabstat 和 summarize 有什么区别？
summarize 输出固定的均值、标准差与极值，分位数需要加 detail 选项；tabstat 可以在 stats() 中自选统计量（如 p25、p75、iqr 等），支持 by() 分组，输出形式更接近论文表格。汇报描述性统计时一般使用 tabstat。
发现最大值明显异常怎么办？
先用 list 命令列出异常观测（例如 list if 变量 > 某阈值），判断属于录入错误还是真实的极端值。录入错误应修正或删除；真实的极端值通过缩尾处理，即 2.2.4 节的 winsor2 命令。
by() 选项和 by 变量: 前缀有什么区别？
tabstat 的分组使用选项 by()；regress、summarize 等命令使用前缀 by 变量: 命令，并且要求先按该变量 sort。两种写法不能混用，否则报 invalid syntax 错误。
