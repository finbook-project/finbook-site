2.5.4固定效应的四种实现

固定效应用于控制不随时间变化的个体异质性（如公司文化、管理层特征）以及所有个体共同受到的时间冲击（如宏观周期）。本节用四种命令控制公司和时间双向固定效应：虚拟变量法（reg i.）、组内变换（xtreg, fe）、吸收一个维度（areg）与多维吸收（reghdfe）。四种写法估计的是同一个模型，系数完全相同。

本节内容包括：
  • 固定效应控制的内容：个体异质性与时间冲击
  • 四种命令的写法、适用情形与速度差异
  • 固定效应吸收截面变异的局限

深度解读
四种命令估计的是同一个双向固定效应模型，系数完全相同（见下方结果表），区别在于运行速度与输出形式：reg i. 在公司数量多时内存与时间消耗大；xtreg, fe 处理一个个体维度；areg 吸收一个维度；reghdfe 支持任意维度且速度最快，是论文中的标准工具。另外需要注意：固定效应吸收所有不随时间变化的变异，当核心解释变量在样本期内基本不变化（如行业属性、产权性质）时，加入公司固定效应后该变量会被吸收，系数无法估计。

常见问题

固定效应和随机效应怎么选择？
教科书方法是 Hausman 检验。公司金融研究中，个体效应与解释变量相关的假定更符合实际，因此几乎一律使用固定效应；随机效应的一致性要求个体效应与所有解释变量不相关，这一要求通常难以满足。
什么情况下不能加入公司固定效应？
当核心解释变量在样本期内基本不随时间变化（如行业、产权性质、地理位置）时，公司固定效应会吸收该变量的全部变异，系数无法估计。此时可以改用行业固定效应，或依靠截面维度的识别设计。
reghdfe 报 command not found 怎么办？
reghdfe 是外部命令，执行 ssc install reghdfe 安装；若提示缺少依赖包 ftools，先执行 ssc install ftools 再重新安装。
四种命令的结果是否应当一致？
在模型设定完全相同（同样的固定效应维度、样本与加权）时，点估计完全一致；不一致通常说明某处的设定存在差异，例如遗漏了某个维度的虚拟变量。
