2.7动态面板与 GMM 估计

被解释变量滞后项进回归：Arellano-Bond 差分 GMM 的 xtabond2

这一节做什么

当解释变量中包含被解释变量的滞后项时（企业的当期行为往往受过去行为影响），模型为动态面板。此时 OLS 与固定效应估计均存在偏误（Nickell 偏差）。Arellano-Bond 差分 GMM 的做法是：先一阶差分消除个体固定效应，再用更深期的滞后项作为工具变量。本节用 Stata 官方的 abdata 就业面板复现 Arellano 和 Bond（1991）的经典动态就业方程。

本节内容包括：
  • 动态面板需要 GMM 的原因：Nickell 偏差
  • xtabond2 的语法：gmm() 型工具、iv() 型工具、nolevel 即差分 GMM
  • 结果表的阅读：AR(2) 检验与 Hansen 过度识别检验

用到哪些数据

abdata.dta
Stata 官方示例：英国公司 1976-1984 就业面板（1031 个观测）
n公司就业数量（对数）
nL1 / nL2就业的一期与二期滞后
w / wL1工资与工资滞后
k / kL1 / kL2资本存量及其滞后
ys / ysL1 / ysL2行业产出及其滞后
⬇ abdata.dta（外部链接）

代码

2.7·1导入数据与描述统计点击带"讲"标记的行查看逐行讲解
1webuse abdata.dta,clear [直接使用网页数据]
2sum n nL1 nL2 w wL1 k kL1 kL2 ys ysL1 ysL2 [对相关变量进行描述性统计]
深度解读
静态面板中常用的组内变换（去均值）在动态面板中失效：变换后的滞后被解释变量仍与误差项相关，即 Nickell 偏差，面板的时间维度越短偏误越重，而公司面板通常年份数远少于公司数。Arellano-Bond 的处理办法是先一阶差分消除个体固定效应，再用两期及更深期的滞后项作为差分方程的工具变量。
2.7·2差分 GMM：xtabond2点击带"讲"标记的行查看逐行讲解
1ssc install xtabond2 [安装xtabond2包，用于GMM估计]
2xtabond2 n L(1/2).n L(0/1).w L(0/2).(k ys) yr*, gmm(L.n) iv(L(0/1).w L(0/2).(k ys) yr*) nolevel robust small [n表示被解释变量，“L(1/2).n L(0/1).w L(0/2).(k ys) yr*”表示所有的解释变量，L.n被指定为GMM估计中使用的工具变量，iv(L(0/1).w L(0/2).(k ys) yr*)是指定的外生变量，nolevel表示差分GMM（若不加即系统GMM），robust表示稳健标准误，small表示采用小样本统计量]
深度解读
xtabond2 的输出按三部分阅读：一看核心滞后项的系数（就业惯性，约 0.6-0.7 且显著）；二看 AR(2) 检验，原假设为差分误差不存在二阶自相关，p 值应大于 0.1，否则工具变量无效；三看 Hansen 检验，原假设为全部工具变量有效，p 值应处于适中水平。经验法则：工具变量个数不超过个体数。差分 GMM 与系统 GMM 的选择：被解释变量接近随机游走时，差分 GMM 存在弱工具问题，系统 GMM 更有效率，但需要额外假设，两种结果常同时报告。

常见问题

什么情况下需要动态面板模型？
当理论表明当期行为依赖过去状态（投资的调整成本、业绩的持续性），或需要区分状态依赖与反向因果时（书中 Wintoki 等 2012 用其考察董事会结构与公司业绩的因果关系），应在回归中加入被解释变量的滞后项，并使用 GMM 估计。
差分 GMM 和系统 GMM 怎么选择？
xtabond2 加 nolevel 选项为差分 GMM，去掉 nolevel 即为系统 GMM。被解释变量接近随机游走或面板不平衡程度较高时，差分 GMM 的工具变量较弱，系统 GMM 更有效率；系统 GMM 需要额外假设滞后差分与个体效应不相关，两种结果同时报告更为稳妥。
AR(2) 检验的 p 值为 0.03 说明什么？
说明差分误差存在二阶自相关，两期及更深滞后作为工具变量的有效性受到质疑。可以调整 GMM 工具的滞后窗口（如 gmm(L.n, lag(2 4))）或修改模型设定；AR(2) 检验通过是 GMM 结果可用的前提。
Hansen 检验的 p 值接近 1 是否越好？
不一定。工具变量过多会使 Hansen 检验失去辨别能力。经验法则是工具变量个数不超过个体数，并可报告压缩工具数量（collapse 选项）后的结果；p 值落在 0.1 至 0.9 之间较为可信。
