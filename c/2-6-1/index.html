2.6.1工具变量与两阶段最小二乘（2SLS）

教育回报率经典案例：iq 内生、med 与 kww 作工具的 ivreg2

这一节做什么

当不可观测的遗漏变量（如个人能力）导致解释变量与误差项相关时，OLS 不再一致。工具变量法寻找一个与内生解释变量相关、又不通过其他渠道影响被解释变量的外生变量来恢复一致的估计。本节以 Griliches（1976）工资方程为案例：iq 与能力高度相关、本身内生，以母亲受教育年限 med 和工作知识测验成绩 kww 作为工具变量，比较 OLS、代理变量法与 2SLS 的结果，并用手工两阶段展示估计结构。

本节内容包括：
  • 工具变量的两个条件：相关性与排除性约束
  • ivreg2 的语法：(内生变量 = 工具变量)，endog() 内生性检验
  • 手工两阶段回归的构造及其标准误问题

用到哪些数据

深度解读
工具变量需要满足两个条件：一是与内生解释变量相关（相关性），可通过第一阶段 F 统计量检验，经验临界值为 10；二是与误差项不相关（排除性约束），无法用数据检验，依靠制度背景与经济逻辑论证。书中 Jayaraman 和 Milbourn（2012）以股票流动性的滞后项与行业中位数作为工具变量、Mian 和 Sufi（2011）以住房供给弹性作为工具变量，均是排除性约束论证的例子。
2.6.1·2OLS 与代理变量回归点击带"讲"标记的行查看逐行讲解
1reg lw s expr tenure rns smsa [核心解释变量是受教育年限s；控制变量包括工作年龄expr、在现单位工作年数tenure、是否住在美国南方rns和是否住在大城市smsa]
2reg lw s iq expr tenure rns smsa
深度解读
代理变量与工具变量是处理同一问题的两条路径：代理变量把不可观测因素中可度量的部分直接控制；工具变量则绕开内生变量。本节中 iq 兼具两种身份：作为能力的代理变量放入 OLS，又因与能力高度相关而被视为内生变量，交由 2SLS 处理。
2.6.1·32SLS：ivreg2 一步到位点击带"讲"标记的行查看逐行讲解
1ssc install ivreg2 [安装ivreg2包，用于2SLS回归]
2ivreg2 lw s expr tenure rns smsa (iq = med kww), robust endog(iq) [工资对数lw为因变量，受教育年限s为自变量，工作年龄expr、在现单位工作年数tenure、是否住在美国南方rns和是否住在大城市smsa是外生变量，指定iq为内生变量，并使用med和kww作为iq的工具变量]
深度解读
阅读 ivreg2 输出的顺序：先看第一阶段 F 统计量，判断工具是否足够强；再看 endog(iq) 的内生性检验，拒绝原假设说明 iq 确实内生、2SLS 有必要；最后看 2SLS 系数的大小与显著性。工具变量个数多于内生变量（过度识别）时，还应参考 Hansen J 统计量，其原假设为所有工具变量外生。
2.6.1·4手工两阶段回归点击带"讲"标记的行查看逐行讲解
1reg iq med kww s expr tenure rns smsa [因变量是作为内生变量的iq，自变量包括工具变量med和kww以及其他外生变量]
2predict v_w [将内生变量的拟合值存储到变量v_w中]
3reg lw v_w s expr tenure rns smsa [因变量是工资对数lw，自变量包括内生变量iq的拟合值v_w和其他外生变量]
深度解读
手工两阶段清楚地展示了 2SLS 的结构：第一阶段用工具变量与外生变量拟合内生变量，第二阶段用拟合值替换内生变量。除标准误不同外，系数与 ivreg2 完全一致；正式研究中不应使用手工两阶段报告推断结果。

常见问题

第一阶段 F 统计量小于 10 怎么处理？
说明存在弱工具变量问题。可以寻找更强的工具变量，或改用对弱工具更稳健的估计方法（如 LIML，ivreg2 的 liml 选项）。ivreg2 输出中同时报告 Stock-Yogo 临界值与 Kleibergen-Paap 统计量，可以对照判断。
工具变量从哪里寻找？
常见的来源包括制度与政策变动、地理或历史变量、解释变量的滞后项等。书中两篇文献（Jayaraman 和 Milbourn 2012；Mian 和 Sufi 2011）分别示范了后两类。论证的重点是说明工具变量只通过内生解释变量影响被解释变量。
endog(iq) 检验不显著说明什么？
说明没有足够证据认为 iq 内生，此时 OLS 更有效率（2SLS 以更大的方差为代价）。常见的做法是主表报告 OLS，附表报告 2SLS，说明系数方向一致、结论稳健。
手工两阶段与 ivreg2 的系数是否相同？
系数完全相同，标准误不同：手工两阶段忽略第一阶段的抽样误差，标准误一般偏小。论文中报告推断结果应使用 ivreg2。
