2.6.3倾向得分匹配（PSM）

当处理组与对照组在可观测特征上不可比时，倾向得分匹配（PSM）用接受处理的概率（倾向得分）为每个处理组个体寻找特征相近的对照，再比较两组的结果差异。本节使用经典的 LaLonde 数据：treatment 表示是否参加就业培训项目，re78 为培训后的收入；psmatch2 进行一对一匹配，随后用 Probit 回归检验匹配后样本的平衡性。

本节内容包括：
  • psmatch2 一对一匹配的语法及其自动生成的变量（_pscore、_weight 等）
  • _weight 的含义与匹配后样本的构造方法
  • 匹配后平衡性检验：Probit 系数应整体不显著

用到哪些数据

lalonde.xlsx
LaLonde (1986) 就业培训数据（22106 个观测）
treatment是否参加培训（处理变量）
re781978 年收入（结果变量）
age/education/married/black/hispanic/no_degree匹配用协变量
⬇ lalonde.xlsx

代码

1倾向得分匹配 psmatch2点击带"讲"标记的行查看逐行讲解
1import excel " lalonde.xlsx", sheet("Sheet1") firstrow clear
2sum
3ssc install psmatch2
4global xlist age educ marr black hisp no_degree
5psmatch2 treatment $xlist, n(1)
深度解读
psmatch2 treatment $xlist, n(1) 的含义：先用 Logit 估计倾向得分，再为每个处理组个体寻找倾向得分最接近的一个对照（一对一近邻匹配，默认有放回、不设卡尺）。命令运行后自动生成 _pscore（倾向得分）、_treated、_support（共同支撑域）、_weight（匹配权重）等变量，下一块代码即利用 _weight 构造匹配后样本。处理组的平均处理效应（ATT）等于匹配后两组 re78 均值之差。
2匹配后样本的平衡性检验点击带"讲"标记的行查看逐行讲解
1gen treat_new=0
2replace treat_new=1 if treatment==1 & _weight!=.
3replace treat_new=. if _weight==.
4probit treat_new $xlist
深度解读
PSM 的可信度依赖两个假设：一是条件独立性，即给定协变量之后，潜在结果与处理状态无关，该假设无法检验，取决于协变量集合是否完整；二是共同支撑，即两组的倾向得分分布存在重叠区间。匹配之后必须进行平衡性检验；进一步可以做 Rosenbaum 敏感性分析，考察结论对不可观测混淆因素的稳健程度。PSM 只能处理可观测的选择，不可观测的内生性仍需要 2.6.1 节的工具变量方法。

常见问题

psmatch2 运行后生成了哪些变量？
_pscore（倾向得分）、_treated（处理标识）、_support（共同支撑域）、_weight（匹配权重）、_id 等。下一块代码即利用 _weight 构造匹配后样本；平衡性检验（pstest）也基于这些变量。
有放回匹配与无放回匹配如何选择？
有放回允许同一个对照被多次使用，匹配质量稳定，但推断依赖重复使用的个体；无放回每个对照只使用一次，对照样本充足时常用。psmatch2 默认为有放回，无放回匹配可加 noreplacement 选项。
匹配之后为什么还要做 Probit 回归？
匹配的目的在于使两组在协变量上不可区分。匹配后以处理标签为因变量、协变量为自变量做 Probit 或 Logit 回归，系数整体不显著说明平衡性良好；若仍显著，说明存在失衡，需要更换匹配方式（如加卡尺、改核匹配）或补充协变量。
PSM 能解决不可观测的混淆因素吗？
不能。PSM 只在可观测协变量上构造可比性；能力、动机等不可观测因素仍可能同时影响处理与结果。LaLonde（1986）正是以此说明用观测数据模仿实验并不自动成立；对不可观测因素需要工具变量、双重差分等方法。
