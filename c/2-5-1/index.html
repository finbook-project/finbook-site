2.5.1静态面板回归：基准回归与结果导出

静态面板模型指解释变量中不包含被解释变量滞后项的面板模型，最常用的估计方法是面板最小二乘法。本节先估计只含核心解释变量的回归，再逐步加入控制变量，并用 est store 暂存、esttab 把两个模型的结果合并输出，即论文中基准回归表的标准制作流程。

本节内容包括：
  • reg 回归输出的阅读：系数、t 值、p 值、置信区间、R² 与样本量
  • est store 暂存回归结果，esttab 合并导出
  • 逐列加入控制变量的基准回归表呈现方式

深度解读
基准回归表通常采用逐列递进的形式：第一列只包含核心解释变量，之后每列加入一组控制变量或固定效应，以显示系数的稳定性。这张表也是后续稳健性检验的参照。esttab 的常用选项包括 se（括号内改为标准误）、star（自定义星号水平）、b(3) t(2)（小数位数）、keep（只保留指定变量）等。

常见问题

esttab 括号内默认是 t 值还是标准误？
默认为 t 值，加入 se 选项后改为标准误。两种形式期刊均有采用，表注中应明确说明括号内为何种统计量。
R² 较低是否说明回归失败？
不能。微观公司面板中被解释变量的变异大部分由个体异质性解释，混合 OLS 的 R² 偏低是普遍现象。公司金融研究关注核心变量的经济含义与统计显著性，不以 R² 的高低为主要标准。
为什么第一列不加入控制变量？
第一列展示核心解释变量与被解释变量的原始关系，之后逐列加入控制变量，可以显示系数的变化幅度。变化幅度小，说明遗漏变量对结果的威胁较小，这本身是一种稳健性证据。
file1 是什么格式的文件？
未指定扩展名时为纯文本文件，保存在工作目录下。使用 using file1.rtf 可输出 Word 表格，using file1.csv 可被 Excel 打开；进入论文之前一般还需要调整格式与星号标注。
