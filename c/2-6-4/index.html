2.6.4双重差分与事件研究（DID）

这一节做什么

双重差分法利用政策在不同个体、不同时间的差异实施，通过比较处理组与对照组在政策前后的变化识别因果效应。本节复现 Beck、Levine 和 Levkov（2010，Journal of Finance）的核心设定：美国各州在不同年份放松银行分支机构管制（_intra），考察其对州内收入不平等（基尼系数）的影响；随后用事件研究法把政策效应按相对年份展开，既考察动态效应，也检验平行趋势假设。

本节内容包括：
  • 基准 DID 回归：xtreg 与州、年份固定效应及州层面聚类标准误
  • 事件研究的构造：相对政策时间、事件虚拟变量与基线归零
  • _b[] 与 _se[] 提取回归系数与标准误，绘制系数-置信区间图

深度解读
双重差分法的识别假设是平行趋势：若无政策，处理组与对照组的走势应当相同。州固定效应吸收不随时间变化的州际差异，年份固定效应吸收全国共同冲击，_intra 的系数反映政策带来的偏离。标准误聚类到州，因为政策在州层面变化，同一州内不同年份的误差相关（与 2.5.5 节的聚类层级原则一致）。
2事件研究：构造相对政策时间点击带"讲"标记的行查看逐行讲解
1generate _tintra = wrkyr - branch_reform [生成政策时间虚拟变量，即上述回归模型中的各个D]
2replace _tintra = -10 if _tintra < -10 [将_tintra中小于-10的值替换为-10，原文进行该步骤的原因在于过于早或者过于晚的年份估计精度太低]
3replace _tintra = 15 if _tintra > 15 [将_tintra中大于15的值替换为15]
4forvalue i=10(-1)1{gen d_`i'=( _tintra == -`i')} [创建一系列名为d_10、d_9、...、d_1的虚拟变量，其取值根据_tintra是否等于-10至-1中对应的值]
5forvalue i=1/15{gen d`i'=( _tintra == `i')} [创建一系列名为d1、d2、...、d15的虚拟变量，其取值根据_tintra是否等于1至15中对应的值]
深度解读
事件研究把双重差分的单一系数展开为相对政策时间的时间剖面：政策前的系数是否围绕 0 波动，直接检验平行趋势假设；政策后的走势反映效应的启动与持续。端点归并（-10 与 15）是事件研究的常规做法：端点附近的样本稀疏，不归并会产生很大的置信区间。
3事件研究：回归并提取系数点击带"讲"标记的行查看逐行讲解
1generate t5 = invttail(48,0.025) [生成在t分布的右尾概率下，自由度为48且显著性水平为0.025时的t统计值]
2xtreg log_gini d_10-d15 wrkyr_dumm*, fe i(statefip) robust cluster(statefip) [使用以log_gini为因变量、d_10-d15为一系列自变量的固定效应模型，并使用了稳健标准误差，聚类到statefip层面]
3forvalue i=10(-1)1{gen b_`i' = _b[d_`i']gen se_b_`i' = _se[d_`i']gen b_`i'LB = b_`i' - t5*se_b_`i'gen b_`i'UB = b_`i' + t5*se_b_`i'} [存储回归系数和标准误，并计算95%置信区间的上下限]
4forvalue i=1/15{gen b`i' = _b[d`i']gen se_b`i' = _se[d`i']gen b`i'LB = b`i' - t5*se_b`i'gen b`i'UB = b`i' + t5*se_b`i'} [同上]

常见问题

为什么政策前的系数必须接近 0？
政策尚未发生时，估计出的系数若显著偏离 0，说明处理组与对照组在政策前已经存在趋势差异或预期效应，平行趋势假设受到质疑，基准 DID 的系数也不可信。事件研究因此既是动态效应的展示，也是对 DID 识别假设的检验。
基期为什么用政策前均值归零，而不是 -1 期？
以单一年份为基准时，该期的估计噪声会整体平移全部系数；以政策前 10 期均值为基准可以平均掉单期噪声，图形更稳健。两种做法文献中均常见，本节按论文原文采用均值归零。
rcap 是什么图层？
rcap（range cap）以指定的上下界（LB、UB）绘制竖直误差线。与 connected 点线图叠加，即得到标准的系数-置信区间图；lpattern(dash) 指定虚线线型，msymbol(circle_hollow) 指定空心圆点。
这篇论文的研究结论是什么？
Beck、Levine 和 Levkov（2010）发现，放松州内银行分支机构管制加剧银行业竞争，改善了对外部融资依赖的低技能劳动者的就业与工资，从而降低州内收入不平等，机制为劳动力需求渠道。配套复现包 bigbadbank 包含论文全部表格与图形的代码。
书中 forvalues 循环一行里有多个命令，如何运行？
书中为节省版面将循环体合并为一行展示，实际 do 文件中每条 gen 或 replace 命令单独占一行（或用 /// 续行）。直接复制书上的单行形式会报语法错误。
