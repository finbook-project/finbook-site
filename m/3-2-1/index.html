3.2.1协整分析：EG 两步法与 Johansen 检验

多个非平稳序列的线性组合可能是平稳的，此时称序列之间存在协整关系，水平序列的回归才有意义，否则容易出现伪回归。本节演示两种检验方法：EG 两步法以人均消费支出与人均可支配收入为例，Johansen 检验以国债利率系统为例，均为书中使用的示例数据。

本节内容包括：
  • EG 两步法：残差 ADF 检验协整
  • Johansen 检验：迹统计量与最大特征值统计量、协整秩的确定
  • 协整关系与伪回归的区别

操作步骤

EG 两步法（书中示例：人均收入与消费）
  1. 国家统计局的季度数据为累计值，先做 X12 季节调整得到 inc_sa 与 cp_sa
  2. 对两个变量分别做 ADF 检验，确认它们同为一阶单整 I(1)
  3. 以 OLS 估计长期关系：书中在方程设定框中输入 cp_sa 和 inc_sa（图 3.2.1）
  4. 对残差做 ADF 检验（不含常数与趋势），统计量小于临界值即拒绝无协整
Johansen 检验（书中示例：国债利率）
  1. 书中运用 Bauer 和 Rudebusch（2020）的数据：选取 3 个月、半年、1 年、5 年、10 年期国债利率，1972-2017 年季度
  2. 将五个序列以 Group 方式打开，View – Cointegration Test
  3. 确定性项选择第三个选项（含截距项、无趋势），最优滞后阶数为 1 期（书中设定）
  4. 输出包含迹统计量与最大特征值统计量两列，从 r = 0 开始逐个与临界值比较：第一个不显著的行之前的显著个数即协整秩

以上步骤依据书中正文与 EViews 菜单整理；对应的 EViews 工作文件见上方数据卡。

常见问题

什么是伪回归？
两个相互独立的 I(1) 序列做水平回归，往往得到很高的 R² 与显著的 t 统计量，但两者并无真实关系，这就是伪回归。判断办法是对回归残差做单位根检验：残差平稳说明存在协整，回归结果才有意义。
EG 检验和 Johansen 检验结论不一致怎么办？
小样本中并不少见（本节示例即出现：EG 不能拒绝无协整，而 Johansen 检验显著拒绝）。此时通常以多变量系统的 Johansen 检验为准，同时报告两种结果；也可以更换检验设定（确定性项、滞后阶数）做敏感性分析。
迹统计量与最大特征值统计量矛盾怎么办？
多数应用以迹统计量为准，因为迹统计量综合了全部秩假设的信息；两者不一致时报告两套结果，并在解释中说明所选秩的依据（经济含义与设定检验）。
协整向量怎么解释？
协整向量刻画变量之间的长期均衡关系，系数可解释为长期弹性或长期乘数，例如货币需求方程中收入与利率的长期系数。协整关系本身不含短期动态，短期调整由误差修正模型刻画（下一节）。
