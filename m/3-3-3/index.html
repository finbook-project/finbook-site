3.3.3贝叶斯 VAR（BVAR）

这一节做什么

VAR 的参数个数随变量数与滞后阶数快速增加，小样本下估计方差大。贝叶斯 VAR（BVAR）通过施加先验分布（最常用的是 Minnesota / Litterman 先验）把滞后系数向零或随机游走收缩，以提高估计与预测的稳健性。本节演示 EViews 中 BVAR 的估计操作。

本节内容包括：
  • BVAR 与普通 VAR 的区别：先验收缩
  • EViews 中 Bayesian VAR 的选项
  • 不同先验紧度下脉冲响应的对比

常见问题

先验分布在起什么作用？
Minnesota 先验认为：自身滞后项系数接近 1（随机游走先验）、其他变量的滞后系数接近 0，且滞后越远收缩越强。先验把估计向这个方向拉动，等价于用先验信息补充样本信息，小样本下估计更稳健。
紧度参数怎么选？
可以用经验法则默认值，也可以把紧度作为超参数、通过样本外预测误差最小化来选择。稳健性检验中报告不同紧度下的脉冲响应（书中图 3.3.22 即不同先验下的对比）。
什么情况下用 BVAR？
变量较多、样本相对不足，或以预测为目标时，BVAR 通常优于普通 VAR。书中图 3.3.23 用 BVAR 考察紧缩货币政策冲击的脉冲响应，是 BVAR 在货币政策研究中的应用。
