3.3.2结构 VAR（SVAR）

VAR 的脉冲响应依赖 Cholesky 分解顺序；结构 VAR（SVAR）通过经济理论对当期关系矩阵施加约束（短期约束）或对长期效应施加约束（长期约束），使冲击具有明确的经济含义（需求冲击、供给冲击、货币政策冲击等）。本节演示 EViews 的 SVAR 估计操作。

本节内容包括：
  • SVAR 的识别：A、B 矩阵与 0 约束
  • EViews 中 Proc – Estimate Structural Factorization 的操作
  • 短期约束与长期约束（Blanchard-Quah）的区别

操作步骤

SVAR 估计
  1. 先按 3.3.1 的步骤估计一个 VAR
  2. 在 VAR 对象窗口选择 Proc – Estimate Structural Factorization
  3. 选择约束类型：短期约束（对 A、B 矩阵的 0 约束）或长期约束（对长期响应矩阵的约束）
  4. 在文本框中按矩阵元素的列堆叠顺序填入约束：固定为 0 的元素写 0，待估元素写 NA（矩阵元素位置的写法书中图 3.3.15 有示例）
  5. 估计完成后，View – Impulse Response 与 View – Variance Decomposition 输出结构冲击的结果

以上步骤依据书中正文与 EViews 菜单整理；对应的 EViews 工作文件见上方数据卡。

常见问题

识别约束从哪里来？
来自经济理论。短期约束的经典例子是货币政策在当期不影响产出与价格（Chritiano-Eichenbaum-Evans 类设定）；长期约束的经典例子是需求冲击对实际变量长期影响为零（Blanchard-Quah）。约束个数需满足恰好识别条件。
SVAR 与 Cholesky 分解是什么关系？
Cholesky 分解等价于对 A 矩阵施加下三角形式的短期约束，即变量按排序依次当期影响后面的变量。SVAR 把这一隐含假设显式化，并允许施加非递归形式的约束，适用范围更广。
约束怎么写？
EViews 中按矩阵元素的列堆叠顺序书写：位置对应元素写 0 表示约束为 0，写 NA 表示由模型估计。约束个数必须使模型恰好识别（未知数个数等于矩条件的个数），过度识别时 EViews 会报告过度识别检验。
书中 SVAR 的应用是什么？
书中图 3.3.18-3.3.20 展示了抵押贷款利差冲击与货币政策冲击的脉冲响应及方差分解，利差冲击对实体经济与信贷条件的解释力是金融危机后宏观金融研究的典型问题。
