3.3.1标准 VAR：定阶、脉冲响应与方差分解

这一节做什么

VAR 把系统中每个变量对其自身与其他全部变量的滞后项回归，不依赖外生的解释变量设定，是宏观金融中最常用的多元时间序列模型。本节按书中 Christiano 等（2005）的四变量示例演示 EViews 的完整流程：滞后阶数选择、VAR 估计、脉冲响应与方差分解。

本节内容包括：
  • VAR 的估计操作与滞后阶数选择（书中：AIC 与 SC 在滞后 3 期同时最小）
  • 脉冲响应函数：Cholesky 正交化与变量顺序
  • 方差分解的阅读

常见问题

滞后阶数怎么选？
看 View – Lag Length Criteria 输出的各准则推荐阶数：AIC 倾向选多、SC 更保守。书中示例中 AIC 与 SC 在滞后 3 期同时最小，直接取 3；两个准则不一致时，通常以 SC 为主、报告另一准则的结果做稳健性。
Cholesky 分解顺序为什么重要？
正交化脉冲响应依赖变量的排序：排在前面的变量当期可以影响后面的变量，反之不能。排序改变，脉冲响应随之改变。选择顺序应依据经济理论（如产出在价格之前、政策变量最后），并报告不同顺序的结果。
脉冲响应和方差分解是什么关系？
两者基于同一组正交化冲击：脉冲响应刻画一个冲击对变量的动态影响路径，方差分解把变量的预测误差方差按冲击来源分解，是对同一系统的两种阅读方式。
VAR 要求变量平稳吗？
标准 VAR 在平稳变量上估计。变量为 I(1) 且存在协整时使用 VEC；没有协整关系时对差分序列估计 VAR。对水平变量直接估计 VAR 的做法存在争议（多数宏观变量的临界值不再标准），书中按规范流程先做平稳性检验。
