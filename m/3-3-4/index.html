3.3.4因子增强 VAR（FA-VAR）

这一节做什么

VAR 能容纳的变量数受样本长度限制，而宏观金融研究往往需要利用大量信息。因子增强 VAR（FA-VAR）从大量宏观序列中提取少数共同因子，把因子与关键观测变量一起纳入 VAR。本节按书中的 FAVAR 实例演示：对变量分组做主成分、按方差解释比例合成共同因子、估计方程并还原不可观测因子。

本节内容包括：
  • 主成分的生成与按方差比例合成共同因子
  • FA-VAR 估计方程的设定
  • 不可观测因子的还原：比例分解

代码

1FA-VAR：主成分合成与估计（EViews 命令窗口）点击带"讲"标记的行查看逐行讲解
1genr x=0.5504*x1+0.1619*x2+0.0872*x3+0.0605*x4 [根据主成分比例合成变量x]
2genr f=0.5598*ef+0.1744*pai [根据主成分比例合成变量f]
3ls x f m2 r [估计方程]
4genr f1=x+0.00000000157*m2-0.008874*r [计算不可观测变量估计值]
5genr z=ef/(0.5598*ef+0.1744*pai) [计算ef在f中所占的比例z]
6genr ef1=z*f1 [得到经济波动和通货膨胀]
7genr pai1=(1-z)*f1
深度解读
本节流程对应 Bernanke 等（2005）的两步法：第一步从大数据集中提取主成分，作为不可观测共同因子的代理；第二步估计 VAR 之后，把因子还原为可观测变量的线性组合，从而对脉冲响应给出经济解释。命令中的 x1、x2 等主成分序列需先由 EViews 的主成分功能生成：把变量组成 Group 后选择 View – Principal Components，并通过 Proc 保存主成分得分。命令逐行输入 EViews 命令窗口执行即可。

常见问题

FA-VAR 与普通 VAR 的区别是什么？
普通 VAR 只能放少数变量，信息集有限；FA-VAR 用主成分从几十上百个序列中提取共同因子，与关键观测变量（如政策利率）一起建模，既保留了大数据的信息，又控制了参数规模，缓解了维度问题。
主成分得分怎么保存？
在 EViews 中把变量组成 Group，View – Principal Components 查看结果，再通过 Proc – Make Principal Components 保存得分序列（如 pc1、pc2），之后即可在命令中引用。配套工作文件 favar.wf1 中已包含保存好的主成分。
为什么按方差解释比例加权合成？
按各主成分的方差解释比例加权，是构造代表性共同因子的常用做法，权重反映每个成分携带信息的相对重要性。本节系数 0.5504 即第一主成分的方差解释比例（见上方表格）。
慢变量与快变量为什么要区分？
FAVAR 识别要求把变量分为慢变（如价格、货币总量，一个月内基本不变）与快变两类：对快变量冲击的当期响应中，慢变量不应有所反应，否则说明因子混入了当期信息。这一约束用于检验因子的信息结构是否合理。
