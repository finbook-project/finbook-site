3.1.2EViews 入门：界面、工作文件与数据导入

这一节做什么

EViews（Econometric Views）是宏观金融实证研究中最常用的计量软件之一，长于时间序列数据的分析与建模。本节介绍 EViews 的版本差异、操作界面、工作文件的创建与数据的导入，是后续协整检验与 VAR 建模的操作基础。

本节内容包括：
  • 创建工作文件：选择数据频率与起止日期
  • 从 Excel 导入数据并命名序列
  • 命令窗口、对象与工作文件的保存

用到哪些数据

股票价格指数（书中示例数据）
书中 3.1.2 的数据导入示例：月度股票价格指数，2001-2011 年，共 5 个序列（书中以 x1-x5 命名）
x1 – x55 个月度股票价格指数序列，2001 年 1 月至 2011 年 12 月（132 个观测）
⬇ 股票价格指数.xls
数据.xls（gdp 与 price）
书中打开现存工作文件示例所含的两个变量（本例中为 gdp 和 price），44 个季度观测

⬇ 数据.xls

操作步骤

创建工作文件
  1. 打开 EViews，选择 File – New – Workfile
  2. 书中以月度股票价格指数为例：频率选择 Monthly，Start date 输入 2001，End date 输入 2011
  3. 确定后生成工作文件，窗口左侧显示工作文件的对象列表
导入数据
  1. 书中演示的粘贴方式：先在命令框中输入 data x1 x2 x3 x4 x5 生成空的 Group，再把 Excel 中的数据直接粘贴进来
  2. 通过菜单导入时：选择 File – Import，确认数据的排列方式（按列为序列）、表头所在行与数据起始单元格
  3. 注意 Excel 需另存为 .xls 格式，否则可能无法导入
界面与对象
  1. 命令窗口中可直接输入命令（如 genr 生成新序列、ls 估计方程、smpl 设定样本区间），回车执行
  2. 书中打开一个现存工作文件演示界面：变量列表包含导入的变量（本例中为 gdp 和 price）
  3. 序列、方程、VAR 等均为对象：双击打开，View 菜单在不同视图之间切换；保存为 .wf1 文件后数据与估计结果随文件保存

以上步骤依据书中正文与 EViews 菜单整理；对应的 EViews 工作文件见上方数据卡。

常见问题

wf1 文件怎么打开？
在 EViews 中选择 File – Open – EViews Workfile，找到 .wf1 文件打开；也可以直接双击文件调用 EViews 打开。配套代码包中提供了本节及后续各节的工作文件，打开后可直接查看每一步操作的结果。
EViews 标准版和企业版有什么区别？
书中图 3.1.1 对两者做了比较：企业版在数据库连接、批量处理与部分高级功能上更强，教学中的绝大多数分析标准版即可完成。学生可通过高校购买或官方学生版获得授权。
样本区间怎么设定？
书中用命令 smpl 设定，例如 smpl 2001 2011 把样本限定在 2001 至 2011 年。回归与检验只在当前样本区间内进行；数据导入后若与工作文件区间不一致，可用 smpl 调整。
没有 EViews 授权怎么办？
书中 3.1.1 的计量软件比较表列出了 Stata、R、Python 等替代工具，第 2 章使用 Stata，第 4 章使用 Python。时间序列分析在 R（vars、urca 包）与 Python（statsmodels）中同样可以实现。
