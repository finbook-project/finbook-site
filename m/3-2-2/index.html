3.2.2误差修正模型（VEC）

协整关系刻画变量之间的长期均衡，误差修正模型（VEC）在其之上补充短期动态：把协整残差（误差修正项）以滞后一期进入差分方程，其系数衡量短期偏离向长期均衡回调的速度。本节以书中 Bauer 和 Rudebusch（2020）国债利率系统的 VEC 估计为例演示操作与结果阅读。

本节内容包括：
  • VEC 的估计操作：VAR 类型选 Vector Error Correction
  • 结果的两块：协整方程（长期）与调整系数（短期）
  • 误差修正项系数的经济含义

常见问题

误差修正项系数怎么解读？
系数衡量上一期偏离长期均衡时本期调整的比例：为负且显著说明偏离会被回调，绝对值越大调整越快；不显著说明短期不向均衡调整，协整关系的解释力弱。若为正，说明偏离进一步扩大，通常提示协整设定或样本处理（如季节调整）需要检查。
VEC 和 VAR 是什么关系？
VEC 是带协整约束的差分 VAR：变量非平稳但存在协整时，直接用差分 VAR 会损失长期信息，VEC 通过误差修正项把长期均衡与短期动态结合起来，是协整系统的标准表示（Engle 和 Granger 表示定理）。
为什么先做 Johansen 检验？
VEC 需要事先给定协整秩：秩为 0 时不存在协整，应使用差分 VAR；秩等于变量个数时系统平稳，可直接用水平 VAR。协整秩由 Johansen 检验确定。
书中的国内价格传导研究是怎么应用的？
书中图 3.2.6 引用的研究对我国上中下游价格系统估计 VEC，考察上下游价格之间的长期传导关系与短期调整速度，是 VEC 在国内研究中的典型应用。
